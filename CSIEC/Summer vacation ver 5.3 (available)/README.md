# cadrop — 接触角测量（基于 OpenDrop 算法思想的独立重实现）

一个面向**固着液滴（sessile drop）接触角**测量的工具：自动定位台面基线、分割液滴、
亚像素提取轮廓、在接触线附近做局部拟合并计算左右接触角，最后提供 Flask 可视化页面与
批量脚本。

> 说明：本实现以 OpenDrop（Berry et al., *J. Colloid Interface Sci.* **454** (2015) 226；
> JOSS **5**(51) 2604）发表的算法为蓝本，但**不包含任何 OpenDrop 源码**。OpenDrop 使用
> GPL-3.0 许可；本项目是对其数学原理的独立重实现，并针对我们的数据做了几处实质改进。
> 文件 `core_old_backup.py` 是旧版本，仅作备份保留。

## 目录结构

```

```

## 快速开始

依赖：`numpy opencv-python flask`。

```bash
cd New
python app.py                 # 启动后浏览器打开 http://127.0.0.1:5000
python app.py --port 8000
python app.py --image-dir "D:\path\to\images"   # 可选：预加载某文件夹（仍可继续上传）

# 批量测量 + CSV（多进程，最快；针对磁盘上的文件夹）
python batch.py --dir "D:\path\to\images" --method auto --out batch_results.csv

# 单元测试
python tests/test_fitting.py
```

## 使用流程（网页）

1. **上传图片**：点击或拖拽图片到左侧上传区（支持 JPG/PNG/BMP/TIFF，可多选）。
   图片保存在内存中，不依赖磁盘路径。
2. **框选液滴大致位置**：点击顶部 **「✂ 框选液滴区域」**，在画布上像截图工具一样拖一个
   矩形框住液滴（含一点台面）；按「清除选区」可取消。框选后再点「测量」，算法只在
   该区域内自动找台面基线与液滴，更快更稳。
3. **测量**：点「测量」得到左右接触角与叠加可视化；可切换拟合方法、开/关图像增强。
4. **批量**：「批量测量全部」对当前所有已上传图片（整图自动测量）出统计摘要。

## 算法流程

1. **基线检测**：逐列 Sobel 找最强“暗→亮”台阶 → RANSAC 拟合近水平直线。与 OpenDrop 的
   “手动拖基线”不同，这里是全自动的。
2. **液滴定位（联合搜索）**：在候选台面边缘上分别尝试“液滴在上”与“液滴在下”（倒置/悬挂
   液滴）两种取向，用 Otsu 分割 + 连通域约束（必须落在台面上、不贴图边框、宽度合理）
   给每条候选基线打分，选最优者。
3. **亚像素轮廓**：逐行取掩码左右极值点，沿边缘法向做抛物线亚像素插值；剔除落在台面
   截断处（无梯度的假边缘）的点。
4. **接触点**：取最低一层里**最外侧**的点（而非简单的 z 最小点——掩码在台面上被平切，
   直接用 z 最小会选中液滴内部）。
5. **局部拟合**：每侧只取接触点附近 `win_frac × 底宽`（默认 0.25，同 OpenDrop 的窗口思路）
   的点做拟合，避免重力压扁的液滴整体轮廓污染局部接触角。方法：
   - `auto`：先试直线，残差大则用圆（默认）；
   - `circle`：几何最小二乘圆拟合，解析求 z=0 处切线；
   - `ellipse`：Halir–Flusser 直接椭圆拟合；
   - `poly`：二次多项式 `r=f(z)`，用 `f'(0)` 求切线；
   - `line`：直线拟合。

## 接触角的符号约定（关键）

基线下定义 `z=0`，`z` 恒指向液滴内部；左右接触点的“指向液滴内部的固体方向”分别为
`+r` 和 `−r`。令轮廓切线向上为 `(tr, tz)`，则：

```
θ_left  = atan2(tz,  tr)
θ_right = atan2(tz, −tr)
```

两侧都落在 (0°, 180°)，**无任何取绝对值**，因此疏水液滴（θ > 90°）也能正确表示。
旧版 `core_old_backup.py` 中 `abs(t[0])` 会强行把角度压缩到 ≤90°，正是该 bug 导致
89.3° 封顶。

## 精度评估

- 基线与 OpenDrop 手动红线的偏差（在两者一致、可比的图像上）中位约 **0.3 px**。
- 用原始像素逐行灰度追踪作为独立真值，对 `drop_image_1.jpg`（真实左右角约 40°/29°，
  液滴本身左右不对称）：本实现得 **42.2°/27.8°**，OpenDrop 得 42.5°/42.0°（其右轮廓
  只追踪到 x≈1064，未到达真实接触点 x≈1245，故右侧约偏差 13°）。
- 176 张图上 `auto` 方法失败率从旧版的 31% 降至 **≈1%**。

注意：`Summer Vacation ver,alpha 3.5 Data/result/` 里的是 OpenDrop 自己的输出，**不能当
真值**——OpenDrop 在这批图上大多失败（其左右角在可验证子集上中位相差 43°）。本项目的
`confidence` 字段（拟合残差 + 点数 + 左右一致性）可用于筛选可信测量。

## API（供前端调用）

| 端点 | 方法 | 说明 |
|---|---|---|
| `/api/upload` | POST | multipart 上传一张或多张图片，返回 id |
| `/api/images` | GET | 已上传图片列表 `[{id, name}]` |
| `/api/image?id=` | GET | 原图（base64 JPEG） |
| `/api/thumb?id=` | GET | 缩略图 |
| `/api/measure` | POST | 测量单张；`{id, method, use_enhance, region?}`，`region` 为 `{x,y,w,h}` 框选区域 |
| `/api/run_all` | POST | 整图批量测量全部已上传图片 |
| `/api/clear_upload` | POST | 删除单张 `{id}` |

`/api/measure` 若带 `region`，则先裁剪该矩形做检测，再把基线/接触点/拟合曲线映射回整图坐标，
叠加图始终画在完整原图上。
