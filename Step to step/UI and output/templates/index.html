    使用说明
    1. 上传一张或多张液滴图片，选中其中一张；
    2. 在左侧逐层选择每一步的方法（每一层都可以换算法）；
    3. 点「运行完整流水线」，右侧会按步骤展示每个阶段的图像与数值；
    4. 「对比所有拟合方法」会额外给出 Young–Laplace / 圆 / 椭圆 / 多项式 / 样条 / 直线 等模型的角度对比表；
    5. 结果可导出为 JSON / CSV，标注图可下载 PNG；「批量跑全部图片」会 用当前方法处理所有已上传图片并汇总成 CSV。

    流水线：① Pre-process（超分 + 定位）→ ② baseline-lemma（6 种基线算法） → ③ Sobel-lemma（6 种边缘 × 3 种阈值）→ ④ Y-L and other methods（9 种拟合模型）。
