# Sobel-lemma 接触线检测 · 准确性改进说明

## 一、背景与问题

审查 Sobel-lemma（Step to step 第 2 步，接触线检测）时，通过代码分析 + 实测，发现两个影响**准确性**的根因：

1. **接触点定位依赖边缘图局部搜索，易被假边缘干扰**
   原 `_refine_contact` 在边缘图上做局部搜索。合成球冠测试中，右接触点被假边缘吸走，偏差达 **42px**（真值 x=219，检出 x=177）。

2. **"成功率 100%" 是假象，接触点异常时不报错**
   原算法对每张图都强行返回接触点，即使左右接触点重合或跑偏也不报错。176 张实测 span 范围 `[0, 2678]`——`0` 表示左右重合、`2678` 表示跑偏，但这些都算"成功"。

## 二、改进内容（4 项）

### 1. 接触点定位改用「掩码轮廓几何交点」

新增 `_contour_contacts(mask, k, b, invert, clearance, contact_band)`：

- `cv2.findContours` 取掩码外轮廓（预处理已保证掩码质量）
- 对轮廓上每个点算带符号距离 `z`
- 在**液滴侧 + 离基线接触带内**找离基线最近的点，取其中 x 最小 / x 最大作为左右接触点

`detect_contact_line` 优先使用它；找不到时回退原边缘图搜索（返回 `None` 而非硬凑点）。

### 2. 加接触点有效性校验

新增 `validate_contacts(left, right, image_w, mask_w)`：

| 校验项 | 规则 |
|---|---|
| span 过小（左右重合）| `span <= 1px` |
| span 过大（超过图像宽度）| `span > 图像宽 × 0.9` |

不合格时 `detect_contact_line` 返回 `ok=False` 并附带失败原因。

### 3. 浮点噪声修复

掩码底部是「z 等值线」，其 z 值因 float32 计算有 ~0.001 的噪声。原 `close = nz <= zmin + 1e-6` 容差太小，只匹配到 1 个点，导致 `_contour_contacts` 返回 None（接触点"假重合"）。

改为 `close = nz <= zmin + 0.5`，覆盖浮点噪声 / 像素离散，同时不卷进圆弧（圆弧在 zmin+1 处才开始）。

### 4. 校验阈值调整

原 `span < 掩码宽 × 0.3` 会把「底部尖的小液滴」（接触点定位正确、span 天然小）误判为失败。去掉这条校验，只保留「左右重合」和「跑偏」两类真错误的识别。

## 四、测试与验证

### 1. 单元/集成测试（TDD，5 个全绿）

| 测试 | 验证内容 |
|---|---|
| `test_contour_contacts_on_spherical_cap` | 合成球冠上，接触点接近几何真值 |
| `test_contour_contacts_handles_float_noise` | 底部 z 有 float32 噪声时，仍能找左右接触点 |
| `test_detect_contact_line_uses_contour_contacts` | `detect_contact_line` 集成后接触点正确 |
| `test_validate_contacts_rejects_degenerate_span` | 左右重合被标记无效 |
| `test_validate_contacts_accepts_small_separate_span` | 左右分开的小 span（底部尖液滴）不被误判 |

运行：`python test_contact_improvements.py`

### 2. 批量实测（176 张液滴图）

| 轮次 | 改进 | 成功率 | span 范围 |
|---|---|---|---|
| 初始 | — | 177/177（假成功）| [0, 2678] |
| 1-2 | 掩码轮廓交点 + 校验 | 162/176 + 14 失败 | [25, 1280] |
| 3 | 浮点噪声修复 | 161/176 + 15 失败 | [31, 1277] |
| **4** | **校验阈值调整** | **176/176，0 失败** | **[14, 1277]** |

## 五、效果

- **接触点精度**：合成球冠右接触点偏差 42px → **<1px**
- **消除假重合**：浮点噪声导致的"左右接触点重合"彻底消除
- **消除假失败**：底部尖液滴不再被误判
- **结果真实性**：`ok` 字段真实反映检测可信度，真错误（重合/跑偏）仍能被识别

## 六、已知限制

1. span 最小的图（如 14px）是**底部尖的小液滴**，接触点定位正确，但这类极小液滴做接触角测量本身意义有限；
2. 接触线检测仍**强依赖预处理**（`locate_drop`）的掩码与基线质量，预处理失败则检测必失败；
3. 后续可继续：
   - **亚像素细化**：沿边缘法向抛物线插值，提高接触点亚像素精度；
   - **基线质量校验 + 回退重定位**：接触点异常时对基线重新拟合；
   - **边缘模式自适应/融合**：自动选最优算子。
